# Run simulation: The First Hour

600 runs (200 per operative) of all three acts, played by the run bot: the planner in every fight, simple
heuristics between fights (it never Glimpses, spends Foresight only to look at Elites, and always Rewinds when it
falls with its Anchor unspent). Generated by `./gradlew :sim:run --args="--runs 200 --out reports/run-latest.md"`.
Deterministic: rerunning gives the same report.
